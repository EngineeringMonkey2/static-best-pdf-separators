1. Bookmarks Method

Uses built-in bookmark structure so users do not need to type all page ranges manually.

Use cases: Construction specs, engineering reports, chaptered manuals.

2. Table of Contents Method

Uses visible TOC text and supports controls like Pages to Skip, Extraction Levels, Naming Levels, and text mode.

Use cases: TOC-driven reports/manuals where native bookmark data is missing.

3. Section Divider Method

Compares pages against a reference divider page using settings such as DPI and similarity threshold.

Use cases: Invoices/forms packets with repeated visual separators.

4. Batches Method

Fixed Size: split every set number of pages. Variable Pattern: repeat sequences such as 1,3,2.

Use cases: Standardized batch documents and recurring multi-part records.

5. Manual / Editor Method (Exact Range Control)

Manual mode supports non-contiguous ranges, including skip-page patterns like 1-1,3-14.

Manual Input Result
1-5Creates an output using pages 1 through 5.
1-1,3-14Includes page 1 and pages 3 through 14, intentionally skipping page 2.
2-4,8-10Combines two non-contiguous ranges into one output set.
1-3,5-5,9-12Includes ranges plus a single page in the middle.

This is useful for removing blank pages, separator sheets, or instruction pages without losing adjacent content.

Why Valotoolbox.com Is Better for Real-World Split Accuracy

Beyond standard page splitting, Valotoolbox includes practical controls that help teams clean messy files, protect section boundaries, and recover from difficult PDF structures without restarting the workflow.

Pages to Skip Controls

Remove blank separators, covers, or inserts before final split output so sections stay clean. Start/end offsets can be stacked, and results can be checked in the Editor view before export.

DPI Tuning for Speed vs Detail

Use lower DPI for faster runs on similar pages, then raise DPI only when boundaries rely on fine visual detail, OCR confidence, or similarity matching on detailed divider pages.

Dual Extractor Flexibility

If one TOC extraction mode produces weak grouping, switch extractors and re-run. This helps recover hierarchy and section mapping across PDFs that look similar but are encoded differently.
